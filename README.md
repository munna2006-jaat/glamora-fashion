## 💻 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run dev client & server
npm run dev

# Web Store: http://localhost:3000
# Admin Control Panel: http://localhost:3000/admin (or http://localhost:5005/admin)
```
